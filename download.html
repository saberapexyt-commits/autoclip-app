Python, ffmpeg and every library are already inside the installer. There is nothing else to install.

Install in three steps

  1. Download and run the installer. Windows may show a blue SmartScreen box because the installer isn't code-signed yet: click More info, then Run anyway. You can compare the checksum above to be sure the file is genuine.
  2. Open AutoClip from the Start Menu or the Desktop shortcut. A short setup asks where your VODs live.
  3. Add a VOD and press Start analysis. Optional extras (GPU, local AI, TikTok) are in Settings whenever you want them.
Already installed? You don't need to come back here. AutoClip checks for updates by itself and offers them inside the app.
