Cookie Policy

Last updated: October 5, 2026

This website does not use cookies. It has no analytics, no advertising, no social-media widgets and no third-party scripts, fonts or images, so there is nothing to track you and no cookie banner to click.

What is stored in your browser

ItemPurposeKept
autoclip-theme (local storage)Remembers whether you chose the light or dark theme. Only created if you press the theme button.Until you clear your browser data

That single setting stays in your browser, is never sent to us, and is strictly functional, so it does not require consent.

Hosting

The site is served by GitHub Pages. Like any web host, GitHub may process your IP address and request details in server logs; see GitHub's privacy statement.

The AutoClip desktop app does not use cookies either. See the Privacy Policy for how it handles data.
