Before you write, it helps to know

  • Your AutoClip version. Settings → Updates shows it.
  • What you were doing and the exact message on screen. Messages name the stage that failed, for example [transcription] or [download].
  • The log file. Open %APPDATA%\AutoClip\autoclip.log (paste that into the Windows Explorer address bar). It contains no passwords or tokens, but it can contain video file names, so glance through it before sharing.

Quick answers

AutoClip won't open

It needs the Microsoft Edge WebView2 Runtime, which is built into Windows 11 and current Windows 10. If it's missing, install it from Microsoft, then try again.

Windows says "Windows protected your PC"

That's SmartScreen, which warns about installers from publishers it hasn't seen often. Click More info → Run anyway. You can verify the download against the SHA-256 checksum on the download page.

My VOD link doesn't download

Twitch and Kick change their sites often. Make sure the link opens the video in your browser (sub-only or deleted VODs can't be downloaded). If it still fails, download the video another way and choose the file with Browse.

TikTok says my app isn't approved

Unaudited TikTok apps can only send clips to your inbox as drafts, or post privately. See Connecting TikTok.

How do I uninstall?

Windows Settings → Apps → AutoClip → Uninstall. Your clips and your settings are kept. Delete %APPDATA%\AutoClip if you also want those gone.
